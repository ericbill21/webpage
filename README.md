# Eric Tillmann Bill — personal homepage

Academic homepage built on [AEM Edge Delivery Services](https://www.aem.live/). Content is authored in [da.live](https://da.live/#/ericbill21/webpage); code (blocks, styles, publication data) lives here.

## Environments
- Preview: https://preview--webpage--ericbill21.aem.page/
- Live: https://preview--webpage--ericbill21.aem.live/

## Development

```sh
npm ci
npx -y @adobe/aem-cli up
npm run lint
```

This repo contains layout code only; all content (pages, publications sheet) is managed in da.live.
